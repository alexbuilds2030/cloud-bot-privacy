1. Общие положения

Настоящая Политика в отношении обработки персональных данных определяет порядок обработки и защиты персональных данных пользователей Telegram-бота MeetingNotes4040bot (далее — «Бот»).

Настоящая Политика разработана в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

2. Цели обработки персональных данных

Оператор обрабатывает персональные данные в следующих целях:

  • регистрация и идентификация пользователя Бота;
  • предоставление доступа к функциональности Бота;
  • прием и обработка передаваемых пользователем аудиозаписей;
  • преобразование аудиозаписей в текст;
  • формирование результатов анализа, резюме встреч, рекомендаций и иных результатов работы Бота;
  • поддержание контекста взаимодействия пользователя с Ботом;
  • обеспечение безопасности и предотвращение неправомерного использования Бота;
  • обработка обращений пользователей.

Персональные данные не используются для целей, несовместимых с указанными выше.

3. Персональные данные, которые могут обрабатываться

В зависимости от способа использования Бота Оператор может обрабатывать:

  • Telegram User ID;
  • имя и фамилию пользователя, если они доступны через Telegram;
  • имя пользователя Telegram (username);
  • текст сообщений, направленных Боту;
  • аудиофайлы и голосовые сообщения;
  • текст, полученный в результате распознавания аудиозаписей;
  • сведения, содержащиеся в переданных пользователем аудиозаписях и сообщениях;
  • результаты обработки и анализа переданной информации;
  • дату и время действий пользователя;
  • техническую информацию, необходимую для функционирования и обеспечения безопасности Бота.

Оператор стремится обрабатывать только тот объем персональных данных, который необходим для достижения указанных в настоящей Политике целей.

4. Обработка аудиозаписей

Пользователь может добровольно передавать Боту аудиозаписи и голосовые сообщения для их распознавания и анализа.

Обработка аудиозаписи может включать следующие действия:

  1. получение файла из Telegram;
  2. временную загрузку файла для технической обработки;
  3. передачу файла в систему распознавания речи;
  4. преобразование речи в текст;
  5. анализ полученного текста;
  6. формирование результата для пользователя.
Аудиофайлы не предназначены для постоянного хранения Оператором. После завершения технической обработки временные копии аудиофайлов удаляются, если иное не требуется законодательством Российской Федерации.

Оператор не использует голос пользователя или иных лиц для установления либо подтверждения их личности.

5. Персональные данные третьих лиц

Передаваемые пользователем сообщения и аудиозаписи могут содержать персональные данные других физических лиц, включая участников записанного разговора.

Передавая Боту такую информацию, пользователь подтверждает, что располагает законными основаниями для записи разговора, обработки содержащейся в нем информации и ее передачи Оператору.

Пользователь не должен передавать Боту персональные данные третьих лиц, если у пользователя отсутствуют законные основания для такой передачи и последующей обработки данных.

6. Правовые основания обработки

Оператор осуществляет обработку персональных данных на основании:

  • Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных»;
  • согласия субъекта персональных данных на обработку его персональных данных;
  • иных оснований, предусмотренных законодательством Российской Федерации, если они применимы.

7. Действия с персональными данными

Оператор может осуществлять следующие действия с персональными данными:

  • сбор;
  • запись;
  • систематизацию;
  • накопление;
  • хранение;
  • уточнение и обновление;
  • извлечение;
  • использование;
  • предоставление лицам, привлекаемым для технической обработки данных, в случаях, когда это необходимо для работы Бота;
  • обезличивание;
  • блокирование;
  • удаление;
  • уничтожение.

Обработка персональных данных осуществляется преимущественно автоматизированным способом с использованием информационных систем.

8. Используемые информационные системы и сервисы

Для обеспечения функционирования Бота могут использоваться:

  • Telegram — для взаимодействия с пользователем и получения направленных пользователем сообщений и файлов;
  • инфраструктура Cloud.ru — для размещения компонентов информационной системы и обработки данных;
  • сервисы распознавания речи (Speech-to-Text);
  • сервисы обработки текста с использованием языковых моделей;
  • базы данных и системы кеширования, необходимые для работы Бота.

Оператор ограничивает объем передаваемой информации объемом, необходимым для выполнения соответствующей технической операции.

9. Сроки обработки и хранения

Персональные данные обрабатываются не дольше, чем этого требуют цели их обработки, если иной срок хранения не предусмотрен законодательством Российской Федерации.

Аудиофайлы обрабатываются временно и удаляются после завершения их технической обработки.

Данные учетной записи пользователя и связанные с использованием Бота сведения могут храниться в течение срока использования Бота пользователем.

Персональные данные подлежат удалению или уничтожению после достижения целей их обработки, прекращения работы Бота либо получения обоснованного требования субъекта персональных данных, если отсутствуют иные законные основания для продолжения обработки.

10. Защита персональных данных

Оператор принимает необходимые правовые, организационные и технические меры для защиты персональных данных от неправомерного или случайного доступа, уничтожения, изменения, блокирования, копирования, предоставления, распространения и иных неправомерных действий.

Доступ к персональным данным предоставляется только в объеме, необходимом для функционирования и сопровождения Бота.

11. Передача персональных данных

Оператор не распространяет персональные данные неопределенному кругу лиц.

Персональные данные могут предоставляться организациям и сервисам, обеспечивающим функционирование информационной системы, исключительно в объеме, необходимом для предоставления соответствующей услуги.

Персональные данные также могут быть предоставлены государственным органам в случаях, предусмотренных законодательством Российской Федерации.
